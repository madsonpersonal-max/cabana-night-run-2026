# Cabana Night Run 2026 — V9.5
## Bonificação pelo Atendente

Regra:
- Atendente pode registrar inscrição bonificada.
- Valor: R$ 0,00.
- Sem PIX e sem comprovante.
- CPF, nome, modalidade e camisa obrigatórios.
- Motivo da bonificação é obrigatório.
- Quem autorizou é obrigatório.
- Registro identifica que a operação foi realizada pelo Atendente.
- Cada bonificação consome 1 vaga do estoque geral.
- CPF duplicado é bloqueado.
- A bonificação entra no cadastro geral com status INSCRIÇÃO CONFIRMADA.
- Administrador mantém o controle administrativo geral e auditoria.
- Homologação local; produção deverá validar permissões e auditoria no backend.
