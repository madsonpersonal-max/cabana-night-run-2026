# Cabana Night Run 2026 — V11.3 Empresas Integradas

Homologação ADM para lotes empresariais.

- Atualização incremental de atletas por planilha.
- Adiciona novos atletas e atualiza somente dados cadastrais de CPFs já existentes no mesmo lote.
- Não exclui atletas automaticamente.
- Bloqueia CPF já cadastrado em outra inscrição/lote.
- Vinculação manual de atleta ao lote também cria/atualiza o registro no cadastro geral.
- A lista "Atletas por empresa/lote" usa o mesmo vínculo e cadastro geral.
- Pagamento de atleta empresarial é controlado no lote, sem cobrança individual.

Esta versão é de HOMOLOGAÇÃO com armazenamento local. Produção deverá usar banco/API central e autorização server-side.
