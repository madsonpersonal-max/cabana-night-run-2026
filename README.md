# Cabana Night Run 2026 — V10.5

Homologação do sistema de inscrições.

## Novidade V10.5
- Recibo de lote empresarial diretamente na aba Empresas.
- Recibo apresenta empresa, CNPJ, responsável, modalidade, vagas contratadas/utilizadas/restantes, valor total negociado, valor equivalente por atleta, validade e status.
- Valor do lote é tratado como **valor total negociado**.
- Valor equivalente por atleta = valor total ÷ vagas contratadas.
- Recibo inclui dados de pagamento do Cabana Clube: Associação Recreativa Cabana Clube, CNPJ/PIX 63.886.204/0001-91.
- Impressão / salvar em PDF pelo navegador.

## Observação
Esta versão continua sendo uma homologação estática com localStorage. Para produção, os dados devem ser persistidos no backend/banco e o recibo deve ser gerado no servidor com controle de permissões e auditoria.
